# Meu editor

Editor de reels com IA: você grava, ele corta as pausas, coloca legenda e elementos no seu estilo e entrega o reel pronto.

## Onde baixar

Abra a **versão mais nova** em [Releases](../../releases/latest) e baixe:

- **meu-editor-gratuito.zip**: para usar no chat do Claude gratuito.
- **meu-editor.zip**: para usar no Claude no computador (plano pago).

Baixe o arquivo inteiro e não descompacte. Siga a aula de instalação.

## Como atualizar

- **No computador:** diga ao Claude "atualiza o meu editor". Ele baixa a versão nova sozinho, e o seu jeito e os seus vídeos continuam iguais.
- **No chat do Claude gratuito:** baixe o meu-editor-gratuito.zip novo aqui e troque pelo antigo nos arquivos do Projeto.
